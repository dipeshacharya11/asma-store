========================================================

Generate OTP using:

secrets

otp = f"{secrets.randbelow(1000000):06d}"

Do NOT use:

random.randint()

OTP:

6 digits
5 minute validity
5 verification attempts
3 resend attempts
60 second resend cooldown
single-use

Store ONLY the hashed OTP.

Use Django password hashing utilities or another secure hash.

Example:

make_password(otp)

Verify:

check_password(entered_otp, stored_hash)

NEVER store plaintext OTP.

NEVER print OTP in production.

NEVER return OTP in JSON.

NEVER put OTP into URL parameters.
